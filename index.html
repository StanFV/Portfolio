FlowKit for Power Automate.

Bewerk, debug en documenteer je Power Automate cloud flows vanuit één browserextensie. Met een volwaardige JSON editor, de run history per actie, een vergelijking van je wijzigingen voordat je opslaat, een overzicht van connectors en licenties en documentatie als HTML of Markdown.

  • Edge & Chrome
  • Versie 1.6
  • Werkt volledig lokaal
  • Geen dataverzameling
→Edge Add-ons →GitHub

AppKit for Power Apps.

De View code van Power Apps Studio is alleen-lezen. AppKit opent een scherm of control in een volwaardige YAML editor met controles tijdens het typen, een outline van alle controls en een geschiedenis van 30 versies. Met één klik vervang je het origineel in Studio waarbij alle verwijzingen blijven werken.

  • Edge & Chrome
  • Versie 1.3
  • Werkt volledig lokaal
  • Geen dataverzameling
→Edge Add-ons →GitHub
